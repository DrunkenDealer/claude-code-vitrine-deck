# Fonts

Self-hosted woff2 subset of Google Fonts used by Vitrine's inspector.

Families:

- Inter
- Manrope
- Sora
- Space Grotesk
- Plus Jakarta Sans
- DM Sans
- Outfit
- Fraunces

All licensed under the SIL Open Font License 1.1. Source:
https://fonts.google.com.

To refresh the files, run:

```sh
node scripts/download-fonts.mjs
```
